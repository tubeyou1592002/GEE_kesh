# Roadmap

Phased roadmap for the GEE_kesh project.

---

## Project Phases (Blocks)

| Block | Name | Status | Description |
|-------|------|--------|-------------|
| **Block 0** | Foundation & Documentation | 🟡 In Progress | Create base documentation, governance, architecture, contracts |
| **Block 1** | GEE Authentication / Connectivity | ⬜ Pending | Set up GEE authentication, Google Cloud project, API access |
| **Block 2** | Data & Image Selection | ⬜ Pending | Define AOI, filters, image/image collection selection logic |
| **Block 3** | Processing Job Model | ⬜ Pending | Define job model, input datasets, processing operations, parameters |
| **Block 4** | GEE Processing Execution | ⬜ Pending | Implement GEE processing execution, export, task submission |
| **Block 5** | Task Monitoring | ⬜ Pending | Monitor GEE task status, polling, retries, timeout handling |
| **Block 6** | Result Retrieval | ⬜ Pending | Retrieve results from GEE, format, storage, delivery |
| **Block 7** | First End-to-End MVP | ⬜ Pending | Complete flow from request to result delivery |
| **Block 8** | Additional Processing Algorithms | ⬜ Pending | Add more processing algorithms beyond MVP |
| **Block 9** | API / UI Expansion | ⬜ Pending | Expand API endpoints, improve UI, add features |

---

## Status Legend

- 🟡 **In Progress** — Currently being worked on
- ⬜ **Pending** — Not started, planned
- ✅ **Completed** — Done and accepted
- 🔴 **Blocked** — Waiting on dependency or decision

---

## Governance Notes

> **This roadmap is a proposal and is subject to change by decision of the Project Manager and Architect.**

- Block priorities and sequencing may be adjusted
- New blocks may be added
- Existing blocks may be split, merged, or removed
- Scope within each block is defined during Block planning by Architect
- Only Block 0 (Documentation) is currently in scope
- No other block is marked as Completed until explicitly accepted by Project Manager
